Concrete deliverables

    Verified local showcase / synthetic fulfillment

    Scenario A / Stock disappears

    A valid plan becomes impossible.

    1. Supplier A offers 12 kits for a $228 total.
    2. A stock event arrives before reservation: zero kits remain.
    3. The frozen plan keeps its obsolete allocation; the common action gateway blocks it.
    4. Pivot invalidates the stock assumption and selects B for $264, inside the fixed $270 cap.
    Target proof: the same event stream produces a visible plan difference and no unauthorized effect.

    Scenario B / ETA slips

    Adapt without forgetting work.

    1. A reservation exists under a 60-minute arrival estimate.
    2. An event changes A’s ETA to 210 minutes, beyond the 180-minute deadline.
    3. Pivot accounts for the reservation and proposes an explicit cancellation and replacement.
    4. Completed effects and cancellation receipts remain in the durable trace.
    Target proof: valid replacement meets the same goal; replay does not reserve or dispatch twice.

    The deliberate failure

    The revision is unsafe.

    A model proposes a replacement above budget. Independent policy refuses it and records why. Nothing is reserved or dispatched. Repeated contradictory signals exhaust the revision budget and pause the run instead of creating an endless loop.

    Specify → build one full loop → break it → measure fairly → explain → publish evidence.

    Architecture: immutable goal → plan → bounded effect → world event → assumption check → validated revision → next effect. Revisions do not rewrite authority.
